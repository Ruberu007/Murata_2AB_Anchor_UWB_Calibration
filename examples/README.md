# SYNTHETIC TEST DATA

The demo is generated deterministically by `uwb_cal/demo.py`. Run `python main.py --demo` or use **Load Demo Project**. It creates separate EVB and custom angle sweeps, distance tests, outliers and a moving tag. It represents no measured hardware performance. Demo projects reject imports of real measurements; create a new project first.

`demo_project.json` is a portable saved synthetic project including copied measurements and results. `sample_rf_diag.txt` demonstrates the firmware text format. `distances.csv` shows the optional ordered measured-distance format.
